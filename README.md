# Persona Resume Agent

> 你的 AI 职业画像师 + 定制简历生成器。持续蒸馏你的经历、技能、性格到 Obsidian，应聘时发一份 JD，自动生成定制简历。

## 这是什么

一个**个人职业画像管理 + 定制简历生成**的工具。传统简历是"投的时候才写、写完就过期"的 PDF，这个工具让你拥有一个**持续生长的职业画像库**：

```
日常对话 / vibe coding / 工作成果
        ↓ 持续蒸馏（AI 追问 + 结构化记录）
  Obsidian 人物画像 Vault
  （经历 / 技能 / 性格 / 项目 / 教育）
        ↓ 发 JD，AI 自动匹配
  内容不足？→ 追问用户 → 新经历同时写入 Vault
        ↓ 调用 resume-master
  定制简历（HTML → PDF）
        ↓
  用户自己投递到招聘软件/网站
```

## 核心特性

- **持续蒸馏**：不是一次填表，而是通过对话不断补充，想到什么说什么
- **四维覆盖**：经历（STAR 结构）、技能（带熟练度）、性格（带事例）、成果（vibe coding 也记）
- **JD 驱动简历**：发一份招聘需求，自动遍历你的画像库，匹配最相关的经历
- **不够就追问**：简历素材不足时，AI 主动追问，追问得到的新经历**同时写入 Vault**，下次自动可用
- **调用 resume-master**：严格遵循 resume-master 的 HTML 编写规范和 PDF 导出，简历质量有保障
- **数据归你**：所有数据存在你自己的 Obsidian 里，纯本地 Markdown

## 快速开始

### 1. 安装

将本仓库复制到你的 Doubao Skills 目录（或任意目录）：

```bash
git clone https://github.com/yourname/persona-resume-agent.git
```

### 2. 初始化你的 Vault

```bash
cd persona-resume-agent
python scripts/init_vault.py ~/my-persona-vault
```

这会在 `~/my-persona-vault` 创建一个完整的 Obsidian 人物画像库。

### 3. 用 Obsidian 打开

用 Obsidian 打开 `~/my-persona-vault` 目录作为 Vault。

### 4. 开始蒸馏画像

对 AI 助手说：

> "开始蒸馏我的人物画像"

AI 会从基础信息开始，每次问几个问题，你想到什么说什么。随时可以中断，下次继续。

### 5. 生成定制简历

应聘时，把招聘需求（JD）发给 AI：

> "根据这个 JD 帮我生成简历：[粘贴 JD]"

AI 会：
1. 解析 JD，提取关键词和要求
2. 遍历你的 Obsidian Vault，匹配最相关的经历和技能
3. **如果素材不足，主动追问你**——追问得到的新经历同时写入 Vault
4. 调用 resume-master 生成 HTML 简历，导出 PDF
5. 你拿着 PDF 自己去招聘软件/网站投递

## 两种核心模式

| 模式 | 触发语 | 做什么 |
|------|--------|--------|
| **画像蒸馏** | "开始蒸馏画像" / 聊起经历 | 追问细节，增量写入 Vault，覆盖经历/技能/性格/成果 |
| **生成简历** | "根据这个 JD 生成简历" | 解析JD → 匹配Vault → 不足就追问（追问即记录）→ 生成PDF |

## 简历生成的闭环（关键）

```
用户发 JD
  → AI 读取 Vault，匹配素材
  → 素材充足？
      ├─ 是 → 生成 HTML → 导出 PDF → 交付
      └─ 否 → AI 追问用户（最多3轮，每次3个问题）
                → 用户回答 → 立即写入 Vault（更新经历/技能/日志）
                → 重新评估是否充足
                → 充足后生成简历
                → 不充足但用户说"没有了" → 用现有素材生成，标注缺口
```

**追问的内容同时写入 Vault**——这意味着你每生成一次简历，你的画像库就更完整一点，下次生成简历时素材就更充足。

## 依赖

- **Python 3.7+**（初始化脚本用，不装也能手动复制模板）
- **Obsidian**（查看和管理 Vault，不装也能用任意 Markdown 编辑器）
- **resume-master skill**（简历导出 PDF 用，未安装时可用浏览器打印 HTML）

## 设计理念

1. **数据归用户**：所有个人数据存在用户本地，不上传任何服务器
2. **增量优于完美**：不追求一次填完，持续生长比一次性完美更有价值
3. **闭环反馈**：简历生成时发现的缺口，回流到画像蒸馏，越用越完整
4. **不代替用户投递**：AI 负责生成高质量简历，投递动作由用户自己完成，避免 AI 乱投
5. **严格遵循 resume-master**：简历质量不妥协，HTML 规范和 PDF 导出都用成熟方案
