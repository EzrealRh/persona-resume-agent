# 待补充清单

> 蒸馏过程中发现的、还没问清楚或用户记不清的信息。
> agent 每次开始蒸馏前先看这个清单，优先追问高优先级项。

## 优先级说明

- **P0 关键缺失**：简历必备信息，没有就没法生成合格简历
- **P1 重要补充**：能显著提升简历质量的信息
- **P2 锦上添花**：有更好，没有也不影响

---

## 待补充项

### P0 关键缺失

- [ ] 姓名、电话、邮箱（个人信息）
- [ ] 最近一段工作经历的详细内容（公司、岗位、时间、成就）
- [ ] 目标岗位方向（职业定位）

### P1 重要补充

- [ ] 每段工作经历的数字结果（用户量/收入/效率提升等）
- [ ] 核心技能的熟练度评估
- [ ] 与目标岗位相关的项目经历
- [ ] 教育背景详细信息（学校、专业、GPA）

### P2 锦上添花

- [ ] 兴趣爱好的深度描述
- [ ] 同事/领导对你的评价
- [ ] 职业价值观的明确表述
- [ ] 作品集/个人网站链接
