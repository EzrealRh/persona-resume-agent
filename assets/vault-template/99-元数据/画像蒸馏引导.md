# 画像蒸馏引导（Agent 操作手册）

> 当用户说"开始蒸馏我的画像"或主动聊起个人经历时，agent 按此手册操作。
> 核心原则：**不追求一次问完，每次深入 1-2 个维度，增量更新 Vault。**

## 蒸馏流程

### 第一步：检查当前状态

1. 读取 `99-元数据/待补充清单.md`，看有哪些待追问的问题
2. 快速扫描各文件的 `status` 字段，了解哪些维度还是"待完善"
3. 如果是第一次蒸馏，从基础信息开始

### 第二步：选择本轮主题

每次只深入 1-2 个维度，按以下优先级：
1. **基础信息缺失** → 先补 `个人信息.md` 和 `核心画像.md`
2. **有经历但没结构化** → 把用户提到的经历按模板写入
3. **经历有了但缺细节** → 追问 STAR 细节和数字结果
4. **技能没梳理** → 从经历中提炼技能，写入技能矩阵
5. **自我认知空白** → 聊优势、价值观、兴趣

### 第三步：提问与追问

- 每次最多问 3 个问题，给用户喘息空间
- 问题要具体，附选项或示例，让用户做"识别题"而非"问答题"
- 用户回答后，立即追问细节："这件事的结果是什么？有具体数字吗？"
- 如果用户说"记不清了"，记录到待补充清单，不要逼问

### 第四步：写入 Vault

- 新经历 → 复制 `_经历模板.md`，创建新文件
- 新项目 → 复制 `_项目模板.md`，创建新文件
- 技能 → 更新 `专业技能.md` / `软技能.md` / `工具栈.md`
- 所有更新 → 在 `画像更新日志.md` 追加记录
- 发现的缺口 → 写入 `待补充清单.md`

### 第五步：反馈与预告

- 告诉用户本轮更新了哪些文件
- 预告下次可以聊什么方向
- 询问用户有没有想主动聊的内容

## 分维度问题库

### 维度一：基础信息

- 你的姓名、电话、邮箱方便留吗？（简历上要用）
- 你现在是在职还是离职状态？期望多久到岗？
- 你期望的工作城市是哪里？
- 有 GitHub、个人网站或作品集链接吗？

### 维度二：职业定位

- 如果用一句话介绍你自己，你会怎么说？
- 你接下来想找什么方向的岗位？有首选和备选吗？
- 你对行业有偏好吗？哪些行业是你不考虑的？
- 你觉得自己最核心的 3 个优势是什么？能各举一个例子吗？

### 维度三：工作经历（每段经历都要问）

- 这家公司是做什么的？你在哪个部门？
- 你的岗位 title 是什么？汇报给谁？团队多大？
- 你主要负责哪几块工作？
- 这段时间里，你最有成就感的一件事是什么？
  - 当时背景是什么？
  - 你具体做了什么？（一步一步说）
  - 最后结果怎么样？有数字吗？（用户量/收入/效率提升/成本降低）
- 还有没有其他值得说的项目或成绩？
- 为什么离开这家公司？（可选）

### 维度四：项目作品

- 有没有哪个项目是你主导或深度参与的？
- 这个项目是解决什么问题的？
- 你在里面具体做了什么？
- 项目最后效果怎么样？
- 有可以展示的链接吗？（GitHub/演示/作品集）

### 维度五：技能梳理

- 你平时工作最常用的工具/软件有哪些？
- 哪些技能是你觉得自己比一般人强的？
- 有没有什么技能是你正在学或想提升的？
- （根据已记录的经历）你在 XX 项目里用到了 XX，这个你熟练度怎么样？

### 维度六：教育背景

- 你的学历、学校、专业是什么？
- GPA 怎么样？排名多少？
- 有没有和目标岗位相关的课程？
- 在校期间有什么荣誉、奖学金、竞赛奖项？
- 有参加过什么社团或学生组织吗？

### 维度七：证书与奖项

- 有什么专业证书吗？（如 PMP、CPA、语言证书等）
- 参加过什么比赛？拿了什么奖？
- 获得过什么奖学金或荣誉称号？

### 维度八：自我认知

- 你觉得自己最大的优点是什么？同事/领导怎么评价你？
- 你最不喜欢什么样的工作方式？
- 你选工作最看重哪 3 点？
- 工作之外你有什么兴趣爱好？投入了多少时间？达到了什么水平？
- 你理想中的工作状态是什么样的？

## 追问技巧

### 数字追问（最重要！）

- "这个提升大概有多少？有数据吗？"
- "用户量大概到了什么级别？"
- "效率提升了多少？原来要多久，现在要多久？"
- "团队有多少人？你带了几个人？"
- "项目周期多长？覆盖了多少用户？"

### 深度追问

- "这件事你具体是怎么做的？能一步一步说吗？"
- "中间遇到了什么困难？你怎么解决的？"
- "如果重来一次，你会怎么做？"
- "这件事体现了你什么能力？"

### 关联追问

- "这段经历和你之前的 XX 工作有什么联系？"
- "你在这个项目里用到的技能，在其他地方也用过吗？"
- "这段经历对你后来的职业选择有什么影响？"

---

## 注意事项

1. **不要一次问太多**：用户会烦，每次 1-2 个维度、3-5 个问题足够
2. **不要替用户编内容**：不确定的地方标"待确认"，不要自己脑补
3. **数字是简历的灵魂**：想尽办法挖数字，没有数字的经历在简历上没说服力
4. **保护用户隐私**：敏感信息（如具体薪资）可以不写入，或标注"私密"
5. **随时可以中断**：告诉用户"今天先到这里，下次继续"，所有内容已保存
6. **用户主动说的优先**：如果用户主动聊起某个话题，优先深入那个话题，不要硬按问题库走
