# AI 求职代理工作流

> 你的 AI 代理代替你去找工作、和招聘方沟通。
> 核心原则：**AI 负责初筛和匹配，关键决策由人做。**

## 代理能力边界

### AI 可以自动做的

- 扫描招聘平台/人才库，根据 [[求职意向]] 搜索匹配岗位
- 读取岗位 JD，与你的 Vault 做匹配度评估
- 生成定制化简历（调用简历生成工作流）
- 写求职信/投递附言
- 回复招聘方的标准化初筛问题（如"你为什么对这个岗位感兴趣"）
- 安排面试时间（与你的日历同步）
- 整理面试记录和反馈

### AI 必须请示你的

- 最终是否投递某个岗位
- 薪资谈判的底线和策略
- 接受/拒绝 offer
- 提供私密信息（如当前薪资、身份证号）
- 任何涉及法律承诺的内容

## 工作流一：自动搜索与匹配岗位

### 触发条件

用户说"帮我找工作" / "搜索匹配的岗位" / 设置了定期搜索任务

### 执行步骤

1. **读取求职意向**
   - 读取 [[求职意向]]，提取目标岗位、行业、城市、薪资范围
   - 读取 [[职业定位]]，提取核心竞争力标签
   - 读取 [[公开资料]]，获取公开版个人信息

2. **搜索岗位**
   - 在指定平台/人才库搜索匹配岗位
   - 搜索关键词：目标岗位 + 核心技能 + 行业
   - 过滤条件：城市、薪资范围、经验要求

3. **匹配度评估**
   对每个岗位，计算匹配度（0-100分）：

   | 维度 | 权重 | 评估方法 |
   |------|------|----------|
   | 技能匹配 | 30% | JD 要求的技能你掌握了多少 |
   | 经验匹配 | 25% | 你的经历与岗位职责的重合度 |
   | 行业匹配 | 15% | 你是否有相关行业经验 |
   | 薪资匹配 | 15% | 岗位薪资范围与你的期望是否重合 |
   | 城市匹配 | 10% | 工作地点是否符合你的要求 |
   | 其他加分 | 5% | 公司规模、发展前景等 |

4. **生成推荐列表**
   - 匹配度 ≥ 80：强烈推荐，优先投递
   - 匹配度 60-80：值得考虑，可以投递
   - 匹配度 40-60：勉强匹配，需要你判断
   - 匹配度 < 40：不推荐

5. **输出给用户**
   每个推荐岗位包含：
   - 公司、岗位、地点、薪资
   - 匹配度分数和各维度得分
   - 你的优势（为什么匹配）
   - 你的差距（缺什么）
   - 建议：是否投递、需要补充什么

## 工作流二：自动投递

### 触发条件

用户确认投递某个岗位，或设置了"匹配度≥80自动投递"

### 执行步骤

1. **生成定制简历**
   - 调用 [[简历生成工作流]]，根据该岗位 JD 生成定制简历
   - 简历命名：`姓名_岗位_公司_日期.pdf`

2. **写求职信/附言**
   - 根据公司和岗位定制，不要用模板
   - 结构：为什么对这个公司/岗位感兴趣 + 你最匹配的 2-3 个点 + 行动号召
   - 控制在 150-200 字

3. **投递**
   - 通过平台/邮箱/API 投递
   - 记录投递时间、岗位、简历版本
   - 在 [[投递记录]] 中追加

4. **后续跟进**
   - 3-5 天未回复，自动写跟进邮件
   - 记录所有沟通历史

## 工作流三：与招聘方 AI 沟通

### 场景：招聘方也是 AI 代理

当招聘方使用 AI 工具读取你的 [[公开资料]] 并发起沟通时：

1. **身份验证**
   - 确认对方是合法的招聘方 AI（公司、岗位、联系方式可验证）
   - 警惕诈骗和信息窃取

2. **信息分级提供**

   | 信息级别 | 内容 | 是否自动提供 |
   |----------|------|-------------|
   | 公开信息 | [[公开资料]] 中的所有内容 | 是 |
   | 半公开 | 详细经历描述、项目细节 | 对方说明岗位后可以提供 |
   | 私密 | 当前薪资、身份证、联系方式 | 必须请示你 |

3. **回答初筛问题**
   - 标准化问题（自我介绍、为什么换工作、期望薪资）→ 基于 Vault 自动回答
   - 技术性问题 → 基于你的技能和经历回答，不确定的标注"需确认"
   - 开放性问题 → 生成草稿，请示你后发送

4. **匹配度互验**
   - 向对方确认岗位详情、薪资范围、团队情况
   - 重新评估匹配度
   - 如果匹配度低，礼貌结束沟通

5. **升级到真人**
   - 当双方 AI 确认匹配度足够（≥70），且核心问题已澄清
   - 安排真人面试或电话沟通
   - 把所有沟通记录整理给你

## 工作流四：面试准备与记录

### 面试前

1. 读取岗位 JD 和公司信息
2. 从你的 Vault 中提取与该岗位最相关的 3-5 个经历
3. 生成面试问答准备：
   - 自我介绍（1分钟/3分钟版本）
   - 常见行为面试题（STAR 结构，用你的经历回答）
   - 技术/专业问题预测
   - 你可以问面试官的问题
4. 生成面试准备文档

### 面试后

1. 记录面试时间、面试官、岗位
2. 记录被问到的问题和你的回答
3. 评估面试表现（1-10分）
4. 记录面试官的反馈和暗示
5. 生成感谢信（24小时内发送）
6. 在 [[面试记录]] 中追加
7. 根据面试反馈更新 Vault（发现的能力缺口、新的经历素材）

```
  - YYYY-MM-DD：待填写

```

## 注意事项

1. **AI 不是你**：所有 AI 发出的信息，重要的必须你过目
2. **保护隐私**：私密信息绝不自动提供，哪怕对方声称是"大厂HR"
3. **防诈骗**：任何要求交钱、提供银行卡、下载不明软件的，立即终止并提醒你
4. **记录一切**：所有投递、沟通、面试都要记录，方便追溯和复盘
5. **定期复盘**：每周汇总投递情况、匹配度趋势、面试反馈，调整求职策略
