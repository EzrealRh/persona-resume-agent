# 未来扩展（当前版本不启用）

> 这个目录里的文件是未来愿景的设计稿，当前版本的 persona-resume-agent 不使用这些功能。
> 保留在这里是为了未来扩展时可以直接启用，不需要重新设计。

## 当前版本的范围

当前版本只做两件事：
1. **画像蒸馏**：通过对话记录用户的经历、技能、性格特质到 Obsidian
2. **定制简历生成**：用户发 JD，AI 读取画像 + 调用 resume-master 生成简历，内容不足时追问并记录

## 未来愿景（这些文件的内容）

| 文件 | 未来功能 |
|------|----------|
| `AI求职代理工作流.md` | AI 自动搜索岗位、评估匹配度、投递、准备面试、跟进 |
| `AI招聘代理工作流.md` | 招聘方 AI 读取求职者公开资料、自动初筛、AI ↔ AI 沟通 |
| `公开资料.md` | 求职者可被招聘方 AI 读取的公开版个人资料 |
| `求职意向.md` | 结构化的求职意向，供 AI 代理自动搜索岗位时使用 |

## 启用方式

当未来要启用这些功能时：
1. 将对应文件移回 `99-元数据/` 或 `00-人物画像/` 目录
2. 在 `SKILL.md` 中添加对应的工作模式
3. 更新 `README.md` 中的功能说明
