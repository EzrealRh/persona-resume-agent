# 人物画像 Vault 使用指南

> 这是你的"人生数据库"。所有关于你的经历、技能、特质都沉淀在这里，agent 只需要读取这个 Vault + 一份 JD，就能生成定制简历。

## 两种使用模式

### 模式一：画像蒸馏（平时做）

随时和 agent 聊天，聊你的任何经历。agent 会：
1. 追问细节（STAR 结构、数字结果）
2. 把新信息增量写入对应文件
3. 更新「待补充清单」和「画像更新日志」

**你不需要自己整理**，想到什么说什么，agent 负责结构化。

### 模式二：简历生成（应聘时做）

给 agent 发一份招聘需求（JD），agent 会：
1. 解析 JD，提取关键词、技能要求、经验要求
2. 遍历整个 Vault，匹配最相关的经历和技能
3. 按 STAR 原则重写经历，突出与 JD 匹配的部分
4. 生成 HTML 简历 → 导出 PDF

## 文件结构说明

| 目录 | 作用 | 更新频率 |
|------|------|----------|
| `00-人物画像/` | 你的核心身份：基本信息、职业定位、一句话总结 | 低频 |
| `01-经历时间线/` | 按时间排列的所有经历（工作/实习/校园），每条一个文件 | 中频 |
| `02-技能矩阵/` | 专业技能、软技能、工具栈，带熟练度标签 | 中频 |
| `03-项目作品/` | 独立项目、作品集、开源贡献等，每条一个文件 | 中频 |
| `04-教育背景/` | 学历、学校、专业、课程 | 低频 |
| `05-证书奖项/` | 证书、奖项、荣誉 | 低频 |
| `06-自我认知/` | 优势、兴趣、价值观——简历的"个人特质"来源 | 中频 |
| `99-元数据/` | 更新日志、待补充清单、agent 操作指南 | 高频 |

## 给 agent 的规则（重要）

当 agent 操作这个 Vault 时：
1. **增量更新，不覆盖**：新信息追加到对应文件，已有内容保留
2. **结构化优先**：经历必须包含 时间/角色/公司/做了什么/结果（有数字）
3. **标签规范**：技能文件用 `熟练度: 精通/熟练/了解` 标注
4. **每次更新后**：在 `99-元数据/画像更新日志.md` 追加一条记录
5. **发现缺口时**：在 `99-元数据/待补充清单.md` 记录需要追问的问题
6. **双链关联**：经历文件中提到的技能、项目，用 `[[技能名]]` 双链

## 快速开始

1. 用 Obsidian 打开这个 `persona-vault` 文件夹
2. 告诉 agent："开始蒸馏我的人物画像"
3. agent 会从基础信息开始问，逐步深入
4. 随时可以中断，下次继续——所有内容都已保存在 Vault 中
